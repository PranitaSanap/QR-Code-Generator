
# QR Code Generator Tool

## Project Description
This Python project generates QR codes from text or website URLs.

## Features
- Accepts text and website links.
- Generates QR code images.
- Saves QR codes as PNG files.
- Simple and easy to use.

## Technologies Used
- Python 3
- qrcode library
- Pillow library

## How to Run
1. Install Python 3.
2. Install the required library:
   pip install "qrcode[pil]"
3. Run main.py.
4. Enter text or a website URL.
5. Enter the output filename.
6. Open the generated PNG image.

## Example
Input: https://www.google.com
Filename: google_qr

Output: google_qr.png
